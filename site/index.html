BSD Setup for Mac

FreeBSD on Apple Silicon Macs, in one command: QEMU + HVF, GELI-encrypted ZFS with boot environments, and an integrity seal checked before every boot.

Install

bash <(curl -fsSL https://bsd.arifcinartekin.me/install)

Uninstall

bash <(curl -fsSL https://bsd.arifcinartekin.me/uninstall)
